# LinkedIn-Style Profile Page Clone

An educational React/Vite clone of LinkedIn's profile page layout. Built as a Pursuit L2 project.

## Sections included

- Sticky top navigation with search, nav icons, badges, Me/Business/Premium buttons
- Profile top card: banner, circular photo, #OpenToWork badge, verification badge, follow/message buttons
- Dismissible verification prompt card
- About section with expand/collapse
- Activity section with Posts/Comments tab toggle and post cards
- Experience section
- Education section
- Skills section
- Right sidebar: job search ad card, More profiles for you, You might like (pages)
- Fixed bottom-right messaging bubble
- Responsive layout (collapses sidebar and affiliations on mobile)

## How to run

```bash
npm install
npm run dev
```

## How to edit profile data

All profile content lives in `src/data/profileData.js`. Change the values there and the whole page updates automatically.

## What's not included

- No LinkedIn API
- No real login or authentication
- No real messaging or connections
- No LinkedIn proprietary assets, class names, or source code

This project is for educational purposes only and is not affiliated with LinkedIn.
